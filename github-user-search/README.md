# GitHub User Search Application

## Project Overview
This project is a React-based application that allows users to search for GitHub profiles and view basic information about the users. It utilizes the GitHub API for data retrieval.

## Task 0: Setting Up a React Project
This initial task focuses on creating the project structure and installing necessary dependencies to prepare for development.

## Features
- Search for GitHub users by username.
- View user's profile information. (To be implemented)

## Technologies Used
- React (with Vite)
- Axios (for API calls)

## Installation and Setup
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/alx-fe-reactjs/github-user-search.git](https://github.com/alx-fe-reactjs/github-user-search.git)
    ```
    (Note: You will need to create this repository on GitHub first.)

2.  **Navigate to the project directory:**
    ```bash
    cd github-user-search
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    npm install axios
    ```

4.  **Run the application:**
    ```bash
    npm run dev
    ```
    The application will typically open in your browser at `http://localhost:5173`.
